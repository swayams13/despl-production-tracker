What changed vs the first mobile concept — and why it's easier

The queue replaced the drilldown

The old concept made the supervisor navigate job → vessel → step → update: four screens before any work. Here the ranked queue is the home screen — the prioritizer already knows what's first, so the top card wears a "do this first" ribbon and 90% of updates are two taps: card → action. A WhatsApp ping deep-links straight to the card, removing navigation entirely.

Built for gloves and daylight

56px primary actions pinned to the bottom (thumb zone), 48px minimum everywhere, one decision per screen, status = colour + icon + word. The theme button cycles Dark → Light → Outdoor: light/dark is a per-user preference (everyone chooses), outdoor is a high-contrast override for bays with open shutters — try all three. While a task is in progress the screen stays awake (wake-lock chip on the card).

Rules render, they don't surprise

An overdue card leads with the reason grid — filing the reason and starting is one motion (invariant #7). A hold-point card keeps its finish button visibly locked with the ITP reference and a Nudge QC escape. Submitting states what happens next: QC verifies, the next stage unlocks. Photo + GPS are evidence; the authoritative timestamp stays the server clock.
