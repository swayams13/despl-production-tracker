P0Assumptions, sources, and what I decided

This board is the pixel reference for Sessions R1–R2. It is built from SPEC-responsive-app-v2 and PLAN-responsive-supervisor-v1. Read this plate before using anything below it.

RECONCILED TO THE REPO TOKEN LAYER

Every colour, font and status word here is read from the repo, not invented: globals.css .theme-industrial for tokens, stage-status.ts for the six status values and their labels, CLAUDE.md for type.

So: accent #FF7A1A, Inter + JetBrains Mono, and Not started · In progress · Awaiting QC · On hold · Overdue · Complete — the brief's "Ready / With QC / Hold / Done" wording is replaced by the canonical labels, since raw or invented status vocabulary is a hard ban.

Three additions the current token layer does not have, all listed in P6 for approval: a --muted-2 third text level, the light and outdoor palettes (D25/D27 need them; v1 is dark-only today), and an icon inside .chip on coarse pointers — the dot alone is not a shape a gloved supervisor can read in sun.

CONTENT COMES FROM THE SEED

Frames now carry the real demo fixtures, so what R2 builds should match what the seed produces:

  • Jobs DESPL-320 and DE0467, unit 320SR01, hold ITP-320-05
  • The reason grid is the master delay-reason list — Material delay, Vendor delay, Drawing revision, Manpower, Client hold, Machine breakdown, Other. Rendered from the DB, so an admin edit changes the grid; six fit 2 × 3 and Other spans the row
  • Login is email + password, matching the real login() action

One open label question (C27): the sheet title shows the process name and the chip shows stage n/25, which is correct per §11.3 — actions target a ProcessPlan, not a stage. The fabrication-detailed names shown are the mockup's scheme, still unconfirmed by SJ.

DESIGN REASONING — 4 CALLS I MADE

1. One card, one action. A queue card never offers two taps. Rank decides what the action is (Claim, Start, File reason, Open), so a gloved thumb cannot pick wrong.

2. Outdoor is a token set, not a filter. It replaces surfaces with true black, thickens borders to 2px, and lifts every status hue — see P1.

3. Overdue leads with the grid. The reason grid is the first thing in the sheet, above the spine, because filing the reason is the gate to starting.

4. Type is the repo's. Inter for UI, JetBrains Mono with tabular-nums for every identifier and number. Noto Devanagari / Gujarati for HI+GU, which sets the line-height floor at 1.45.
