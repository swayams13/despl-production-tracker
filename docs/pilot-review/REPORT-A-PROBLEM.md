# How to report a problem

Send Swayam, for each problem:

1. **A screenshot of the whole screen** including the address bar (it shows the page and job).
2. **Your name and role** (Planner, Fabrication supervisor, QC, Stores…) and **the time** (the system keeps its own record).
3. **What you did**, step by step: "Opened job DESPL-320, unit 320SR03, tapped Start on Weld Edge Prep."
4. **What you expected** and **what happened instead**. Copy the red or yellow message exactly as written.
5. If the page said "Application error" or never finished loading: say so, and try once more before reporting.
6. If you were refused and think the refusal is wrong: say that. Refusals are on purpose; the screenshot tells us whether the rule or the data is wrong.

Do not send passwords. Do not try to work around a refusal by using someone else's login.
